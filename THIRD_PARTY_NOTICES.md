# Third-Party Notices

## Current Default Branch

The current default branch distributes no course source, CMSIS copy, GigaDevice or STMicroelectronics vendor library, startup file, CubeMX-generated project, external board image, font, or binary component.

`include/control_app.h`, `src/control_app.c`, `tests/test_control_app.c`, and `tools/control_demo.c` are new repository-authored portable Host code. They do not contain vendor register definitions or copied course application source. The asset decisions behind that boundary are summarized in [Local Asset and Source Boundary](docs/source-provenance.md).

Documentation may refer to ARM Cortex-M, CMSIS, GD32F4, STM32F4, Keil MDK-ARM, and STM32CubeMX. These references do not include or relicense the corresponding third-party software.

## Excluded Source Material

Course applications, teacher/project-specific code, complete vendor libraries, generated projects, external images, and files without established redistribution permission are excluded from the current default branch. Earlier commits remain reachable because history rewriting was prohibited.
