# Course source index

Selected original projects are stored inside each technical group under `projects/**/course/`.

The source files and Keil/CubeMX configurations are copied without content changes. Generated build files and unrelated vendor packages are omitted. See [`../docs/project-selection.md`](../docs/project-selection.md) for the selection rationale and [`../docs/course-source-sha256.csv`](../docs/course-source-sha256.csv) for file-level integrity records.

Future personal implementations should use a `practice/` directory beside the corresponding `course/` directory. No empty practice tree is created in this version.
